# Муравейник: Осада

Tower defense в духе Kingdom Rush про оборону муравейника. Браузерная игра без единой
runtime-зависимости: TypeScript + Canvas 2D, весь арт нарисован кодом. Работает на ПК и на
телефоне (мышь и палец), собирается в один `index.html`, который открывается двойным кликом.

## История

Старый дуб рухнул в грозу, и лесная подстилка вздрогнула. Из гнилого пня полезли термиты,
с упавшего гнезда поднялись осы, а из-под корней выползли жуки. Королева кладёт новый выводок,
и колония должна выстоять до конца сезона. Игрок — воевода муравейника: расставляет башни и
в нужный момент зовёт на тропу заклинания колонии, в том числе дружину героя Жвала.

**Акт 1 — Оборона муравейника**:
1. «Опушка у старого дуба»: одна тропа-змейка, 12 волн.
2. «Корни павшего дуба»: две тропы, слева и снизу, сходятся у восточного входа; 14 волн,
   в финале два жука-носорога.
3. «Ночь у гнилого пня»: ночная карта, муравейник в центре, враги выходят из норы в пне слева
   и из темноты справа; 16 волн, в финале термитная матка, которая рожает термитов на ходу.

**Акт 2 — Поход на термитник**: колония идёт в наступление, игрок защищает передовые лагеря
всё глубже на вражеской территории.
4. «Переправа через ручей»: две тропы через брёвна-мосты, стрекозы и пиявки; 14 волн.
5. «Подножие термитника»: стена термитника во весь верх, три хода-норы, термиты-подрывники,
   которые взрываются рядом с солдатами; 15 волн, самый тугой уровень похода.
6. «Сердце термитника»: пещера со светящейся грибницей, финальный босс — королева термитов,
   призывает термитов-солдат на ходу; 14 волн.

## Запуск

```bash
npm install
npm run dev
```

Dev-сервер слушает все интерфейсы (`host: true`). Чтобы открыть на телефоне, подключи его к той же
Wi-Fi сети и набери адрес ПК, который Vite печатает в консоли (строка `Network:`), например
`http://192.168.1.20:5173`.

## Сборка

```bash
npm run build
```

Результат: `dist/index.html` — один файл со всем кодом внутри. Его можно открыть локально,
залить на любой статический хостинг (GitHub Pages, itch.io, Netlify) или отправить другу. Рядом
лежат файлы для установки на телефон из `public/`: манифест, service worker и иконки; без них игра
тоже работает, просто не ставится как приложение.

Каждый push в `main` собирает игру в GitHub Actions и выкладывает `dist/` на GitHub Pages
(`.github/workflows/pages.yml`, в настройках Pages источник «GitHub Actions»).

Rollup подключён в WebAssembly-сборке через `overrides` в `package.json`: Smart App Control в
Windows 11 блокирует его нативный модуль, и без подмены не запускались ни `npm run dev`, ни
`npm run build`. На скорость сборки это почти не влияет.

## Экраны и прогресс

Заставка → экран кампании → вступление с историей и выбором сложности → бой → итоги со звёздами.
Новичок по «Играть» сразу попадает на обучение. На экране кампании слева вкладки восьми актов
(цвет ландшафта, звёзды акта или замок), в центре девять карт выбранного акта, справа пролог-обучение
и бесконечная осада. Звёзды: 3 за 90 % уцелевших личинок, 2 за половину, 1 за победу; сложность на
число звёзд не влияет, но на карточке пишется самая высокая сложность, на которой карта пройдена.
Первый акт открывает обучение; все карты открытого акта доступны сразу, в любом порядке; следующий
акт открывается, когда на каждой карте предыдущего есть хотя бы одна звезда (в `npm run dev`
открыто всё). Победа, закрывшая акт, показывает строку финала акта и какой акт открылся; на экране
победы есть «Дальше» к следующей карте. Звёзды, перки, выбранная сложность, рекорды осады и
настройки хранятся в `localStorage`, на экране кампании есть «Сбросить прогресс» с подтверждением
вторым тапом. Старые сохранения читаются: кто уже брал звёзды, тому обучение засчитано, а акт, в
котором уже есть победа, открыт.

## Кампания: восемь актов по девять карт

`src/game/campaign.ts` собирает кампанию: 72 карты в восьми актах. Первые два акта — нынешние
уровни, нарисованные вручную (по две первые карты и финал акта), а между ними по шесть
сгенерированных карт в тех же темах (поляна, корни дуба, ночь у пня; ручей, пещера, термитник).
Акты с третьего по восьмой — новые ландшафты по девять сгенерированных карт: пустыня, горы,
джунгли, снега, лес, Азия. Названия и короткие истории карт на двух языках лежат в
`src/game/maptexts.ts`.

- **Ландшафты** (`src/render/biomes.ts`): своя фактура земли, мелкий декор и крупные препятствия
  (на них нельзя ни строить, ни прокладывать тропы) и своя полоса поперёк карты с мостами там, где
  её пересекают тропы. Пустыня: песок с рябью, кактусы, кости, перекати-поле, скалы из песчаника.
  Горы: альпийский луг, галечная тропа, валуны, эдельвейсы, ущелье с подвесными мостиками. Джунгли:
  огромные листья, папоротники, орхидеи, река с брёвнами. Снега: наст с блёстками, сугробы, шишки,
  ледяные иглы, замёрзшая река (её переходят без моста). Лес: хвоя, мох, грибы, спиленные пни,
  ручей. Азия: бамбуковые рощи, сакура, каменные фонари, пруды с карпами, ручей с красными мостиками.
  У первых двух актов свои крупные акценты: цветущие кусты, камыши у воды, термитные башенки,
  сталагмиты в пещере, светящиеся кольца грибов ночью, узлы корней под дубом.
- **Фон карты** (`drawTerrain` в `src/render/art.ts`): земля из больших светлых полян и тёмных низин,
  мягких пятен поменьше и пучков травинок (на песке, снегу и в пещере — крапинки); клетки под башни
  лишь чуть подкрашены в шахматку, на тёмной земле ещё слабее. Тропа со скруглёнными поворотами и
  неровной кромкой: вытоптанная трава по краям, колеи, светлая середина, камешки и травинки на краю
  через неравные промежутки. Декор лежит группами (клумба одного цвета, кольцо грибов, груда
  камней, клевер, опавшие листья; у ландшафтов свои) и одиночками, не залезает на тропы, воду,
  препятствия, ствол и корни дуба. Корни дуба — изогнутые, сужающиеся, с корешками и тенью. По
  краям экрана лёгкая виньетка (кроме пещеры).
- **Карты** сгенерированы `sim/mapgen.ts`: тропа — случайное блуждание по клеткам 16×9 отрезками
  по 2–6 клеток с поворотами на 90°, от 16 до 32 клеток длиной; между её витками и между разными тропами всегда остаётся ряд
  клеток под башни, полосу воды или ущелье тропа пересекает только поперёк, дополнительные тропы
  вливаются в первую на прямом участке задолго до муравейника. Из десятков попыток каждая карта
  берёт одну из шести лучших по оценке (клетки у тропы, места, откуда башня бьёт по двум участкам
  сразу, повороты, тропа на всё поле без пустых углов, без длинных прямых), каждая вторая отражена
  слева направо. Крупные препятствия ставятся в пустые места подальше от тропы. Геометрия хранится данными в
  `src/game/maps.gen.ts`, игра её только читает.
- **Волны** собираются из «угрозы» карты, как в бесконечной осаде: состав врагов свой у каждого акта
  (в пустыне чаще жуки, пауки и осы, в джунглях пиявки, слизни и стрекозы и т.д.), каждая пятая
  волна воздушная, каждая седьмая бронированная, в последней выходят боссы, к финалу акта тяжелее.
  Численность волн растёт с номером волны и немного с актом, а трудность карты задаёт множитель
  здоровья врагов: его подобрал игрок-робот так, чтобы в начале акта у смешанной стратегии оставалось
  около 15 личинок, к финалу акта около 9 (с перками, которые к этой карте обычно уже куплены).
  Подбирается именно здоровье, а не численность: лишние враги приносят нектар, и доход рос бы вместе
  с угрозой, робот выигрывал при любой численности.
  Проверка всех 66 карт пятью стратегиями (`npx tsx sim/campaign.ts check`): обе смешанные
  стратегии проходят каждую карту (девять карт после подбора пришлось ослабить на 8 % командой
  `soften`); «качать, а не строить» падает на финале Леса, «только стрелки» на двух картах Снегов,
  а без заклинаний робот проигрывает около половины карт со второго акта: там кислотный дождь и
  дружина обязательны. Первый акт ослаблен так, чтобы его проходили все пять стратегий, в том числе
  без заклинаний (`soften --no-spells`; у ручных «Корней павшего дуба» здоровье врагов ×0.85):
  новичок ещё может ими не пользоваться.
- **Постройки в стиле акта** включаются по ландшафту карты (`setTowerStyle` в `art.ts`, муравейник —
  параметром `drawAnthill`). Готова Азия:
  - стрелки — связка объёмных бамбуковых стеблей на речных камнях, витые обвязки, настил в
    обруче, частокол со светящейся кислотой в срезах, стрелки в шляпах-каса; со 2-го уровня
    знамя-нобори, с 3-го бумажный фонарь;
  - казарма — пагода на каменном цоколе, норэн у входа, 2-й ярус и фонари на углах, золотой шпиль;
  - грибница — коряга с полками линчжи в сине-белой вазе, лаковая подставка, бумажный оберег;
  - катапульта — бамбуковая рама на стойках над лаковым поворотным кругом, плетёная корзина;
  - муравейник — кладка по низу холма (расступается у троп), тории над входом, каменные фонари,
    знамёна, лепестки сакуры.

  Общие мелочи наборов (разброс, древко, герб, латунь, брус) лежат в `src/render/kit.ts`.

```bash
npx tsx sim/campaign.ts gen       # заново сгенерировать тропы всех карт (сложность сбрасывается)
npx tsx sim/campaign.ts tune      # подобрать сложность всем картам (или: tune a3s4 a3s5)
npx tsx sim/campaign.ts soften a5s5 # снижать сложность по 8 %, пока обе смешанные стратегии не выиграют
npx tsx sim/campaign.ts soften --no-spells a0s3  # то же, но выиграть должен и робот без заклинаний
npx tsx sim/campaign.ts check     # прогнать все карты пятью стратегиями (или: check oak-roots a0s3)
```

## Обучение

«Учебный плац» (`TUTORIAL` в `src/game/levels.ts`) — пролог перед кампанией: пять коротких волн
на одной тропе, игрок по подсказке проходит его примерно за две минуты. Воевода Жвал ведёт по
шагам (`src/game/tutorial.ts`): панель с подсказкой под верхней панелью и золотая рамка со
стрелкой на нужной клетке или кнопке. Шаги по порядку: стрелки на углу поворота, первая волна
и бонус за ранний вызов, нектар и личинки, казарма, улучшение башни, грибница против ос,
кислотный дождь по толпе, перезарядка, ускорение x2, «Дружина» против жука в панцире.

- Следующая волна стоит, пока игрок не выполнит задание: кнопка волны пишет «Волна подождёт».
- На заклинаниях время замирает: поле чуть синеет, мир стоит, а кнопки и тапы работают.
  Толпа сначала заходит на поле подальше от края, и только тогда время останавливается.
- Не хватает нектара на задание — королева подкидывает недостающее.
- Учебные враги слабее обычных (здоровье ×0.6 и до ×0.8 к пятой волне), сложность не
  выбирается, звёзд нет: обучение открывает кампанию и бесконечную осаду. На вступлении есть
  «Пропустить обучение».

Проверка: `npx tsx sim/tutorial.ts` проигрывает плац так, как велят подсказки, и сейчас
проходит его без единой потерянной личинки.

## Бесконечная осада

Испытание для рекордов (`src/game/endless.ts`): большая поляна 28×16 клеток, втрое больше
обычной карты, и одна тропа спиралью к муравейнику в центре. Вход слева посередине, дальше два
витка по часовой стрелке внутрь: вверх, по верхнему краю, вниз, по нижнему, и второй виток на три
клетки внутри первого; последний отрезок идёт к муравейнику по седьмому ряду. Между витками по два
ряда клеток: башня там после улучшений достаёт до обоих витков, а внутри спирали вокруг муравейника
есть место для последнего рубежа. Тропа длинная, около 10 500 пикселей: термит идёт её почти две с
половиной минуты, поэтому на поле одновременно несколько волн. У входа, откуда выйдет следующая
волна, красный флажок; если вход за краем экрана, у края стрелка, и тап по ней ведёт камеру туда.

- Волны бесконечны и собираются на лету, но детерминированно: одна и та же волна всегда одна и
  та же. Бюджет волны считается в «угрозе» (здоровье с поправкой на панцирь, регенерацию и полёт),
  поэтому волна из слизней не тяжелее волны из ос. Новые враги появляются по одному виду за
  несколько волн, каждая пятая волна воздушная, каждая седьмая бронированная, каждую десятую
  ведёт босс: носорог, матка, королева, потом по кругу и больше.
- Здоровье врагов растёт на 6 % за волну сложными процентами, а доход линейно: рано или поздно
  колония падает, вопрос только на какой волне.
- Рекорд — самая поздняя отбитая волна (все её враги убиты или дошли до муравейника, а колония
  стоит), при равенстве больше повергнутых врагов. Позвать волну мало, её надо пережить; а медленный
  босс, который ползёт по спирали минутами и рожает солдат своей волны, не держит счёт следующих волн.
  Рекорд свой на каждой сложности, сохраняется при поражении, при выходе к уровням и когда вкладку
  скрывают.

Карта двигается камерой (`src/game/camera.ts`): тянуть пальцем или мышью, щипок или колесо
меняют масштаб, на ПК ещё стрелки и `+`/`-`. В начале карта видна целиком, насколько влезает в
экран. Интерфейс рисуется поверх в координатах экрана; фон большой карты печётся целиком один
раз с ограничением по пикселям, чтобы телефону хватило памяти.

## Настройки: язык и звук

Кнопка «Настройки» есть на заставке, на экране выбора уровня и в паузе (`Esc` закрывает). Там выбор
языка (русский и английский) и две громкости, музыка и звуки, шагами по 5 %: кнопки «−»/«+» или тап по
полосе. Язык по умолчанию берётся из браузера (русский для ru/uk/be/kk, иначе английский). Все тексты
собраны в `src/game/i18n.ts`: русский остаётся исходником в `config.ts`, `levels.ts` и `perks.ts`,
английские переводы лежат там таблицами по id, интерфейс берёт строки через `t('ключ', ...)`.

Звук целиком синтезируется WebAudio в `src/engine/audio.ts`, звуковых файлов нет: эффекты (выстрелы,
попадания, стройка, заклинания, рог волны, «Напор», победа и поражение) и генеративная музыка в ре миноре
с двумя режимами, спокойным для меню и быстрым с ударными для боя; режим меняется на границе такта. Ядро
шлёт события через `GameCtx.sound(id)`, симуляция в Node их игнорирует. Контекст звука создаётся по
первому тапу или клавише, как требуют браузеры; одинаковые эффекты не чаще раза в несколько десятков
миллисекунд, чтобы залп башен не превращался в треск.

## Любые экраны без пустых краёв

Игровое поле всегда один и тот же кадр 1280x720: уровни и баланс от экрана не зависят. Если экран
шире или выше кадра, мир дорисовывается на полях вокруг него, а не заливается тёмными полосами:

- фон печётся под видимую область: трава, декор, ручей, ствол павшего дуба, стена термитника и
  скалы пещеры продолжаются до краёв экрана; поля рисуются своим генератором, поэтому декор самого
  кадра не перетасовывается от ширины экрана;
- тропы, которые приходят из-за края карты, тянутся до края экрана, и враги ещё не вышедшей части
  волны уже идут по ним на подходе; это только отрисовка по таймерам волны, симуляция та же, и враг
  выходит на карту ровно там и тогда, где его создаёт симуляция; кто выходит сразу при старте
  волны, проявляется за долю секунды;
- угловые блоки интерфейса (ресурсы, скорость и пауза, хотбар, кнопка волны) прижимаются к
  настоящим углам экрана и обходят вырез камеры по `env(safe-area-inset-*)`;
- картина заставки идёт по ширине экрана; на высоком экране сверху и снизу её размытое продолжение.

Поля ограничены пропорциями 21.6:9 по ширине и 5:4 по высоте (`MAX_EXTRA_X` и `MAX_EXTRA_Y` в
`src/engine/canvas.ts`): на ещё более вытянутых экранах и в портрете дальше остаются тёмные полосы.

## Телефон: полный экран и установка

На телефоне игра разворачивается на весь экран по первому тапу и закрепляет альбомную ориентацию:
браузеры разрешают это только в ответ на жест, не при загрузке страницы. В настройках есть
переключатель «Полный экран»: по умолчанию он включён на телефоне и выключен на ПК. На iPhone
браузерного полного экрана нет: там кнопка «Установить» на заставке и кнопка в настройках
показывают подсказку, как добавить игру на главный экран через «Поделиться». Со значка игра
открывается без панелей Safari, но прогресс у значка свой: Safari и значок хранят его отдельно.
Посмотреть эти экраны на ПК можно в `npm run dev` по адресу `http://localhost:5173/?iphone`.

Игру можно установить как приложение: Chrome показывает кнопку «Установить» на заставке или пункт
«Установить приложение» в меню. Установленная игра сразу открывается на весь экран без адресной
строки и после первого запуска работает без интернета. Для этого в `public/` лежат
`manifest.webmanifest`, `sw.js` (сначала сеть, без сети кэш) и иконки в `icons/`, вырезанные из
картины заставки. Service worker регистрируется только в собранной игре, в dev его нет.

Холст подгоняется под видимую область окна по `visualViewport` и сверяет размер каждый кадр:
Chrome на Android после поворота телефона оставлял высоту от вертикального положения, и игра
уезжала вниз за край экрана.

На iPhone звук играет и при включённом беззвучном режиме: игра просит у Safari режим
воспроизведения через `navigator.audioSession`, а на старых iOS без него включает зацикленную
тишину в обычном звуковом элементе. Если музыка и звуки в настройках выключены, режим не меняется,
и музыка других приложений не прерывается.

## Сложность

Выбирается на экране перед уровнем и запоминается. Баланс уровней рассчитан на «Нормально».

| Сложность | Здоровье врагов | Нектар (старт и награды) | Личинки |
| --- | --- | --- | --- |
| Легко | ×0.85 | ×1.15 | как в уровне |
| Нормально | ×1 | ×1 | как в уровне |
| Сложно | ×1.15 | ×1 | половина |

Множители в `DIFFICULTIES` в `src/game/config.ts`; применяются в `World` при появлении врага,
начислении награды и подсчёте стартовых личинок.

## Улучшения колонии (перки)

Звёзды тратятся на экране «Улучшения колонии»: восемь постоянных улучшений по 1 звезде за ранг —
урон стрелков, здоровье солдат (казармы и дружины), яд грибницы и споровой тучи, урон катапульты,
нектар за врагов, стартовый нектар, уровень Жвала и перезарядка заклинаний, дополнительные
личинки. Звёзды возвращаются без потерь кнопкой «Вернуть все звёзды», так что наборы можно
менять под уровень. Данные в `src/game/perks.ts`, эффекты применяются в `Tower.stats`,
`SpellBook` и `World`.

## Застройка по клеткам

Поле разбито на клетки 80×80 (ровно 16×9). Башня занимает одну клетку, строить можно где
угодно, кроме троп, воды, стены термитника, пня, холма муравейника и панелей интерфейса.
Сетка считается автоматически из описания уровня (`World.makeGrid`). Доступные клетки
нарисованы шахматным газоном (чуть светлее и чуть темнее), недоступные остаются сплошной
травой, так что сразу видно, где можно строить; на ПК клетка под курсором подсвечивается,
выбранная клетка обведена пунктиром. Тропы идут только по горизонтали и вертикали, их точки
лежат на центрах клеток (внутренние точки прижимаются автоматически), а повороты строго на
90° с едва заметным скруглением: внутренняя угловая клетка остаётся свободной, и башню можно
поставить прямо в угол.

## Заклинания и герой

Героем никто не управляет: вместо этого в хотбаре слева внизу три заклинания колонии с
перезарядкой. Тап по кнопке (или `Q` / `W` / `E`), затем тап по точке на поле — одинаково на ПК и
на телефоне. На ПК под курсором виден круг действия.

| Заклинание | Что делает | Радиус | Перезарядка |
| --- | --- | --- | --- |
| Кислотный дождь | рабочие разом плюют в точку: 140 урона всем в круге, панцирь не учитывается, достаёт летающих | 90 | 24 с |
| Дружина | воевода Жвал и два солдата выходят в точку на 16 с, держат врагов и бьют в ближнем бою | 60 | 32 с |
| Споровая туча | облако спор на 8 с: замедление вдвое, яд, разовое оглушение при входе | 75 | 26 с |

Жвал — муравей-солдат в шлеме из шляпки жёлудя, с листом-щитом и копьём-шипом. На поле он на
автопилоте: держит ближайшего наземного врага, бьёт всех рядом и сам пускает «Жвалы» (урон и
оглушение вокруг), когда рядом двое и больше врагов. Выходит 3-го уровня из пяти, перк «Закалка
воеводы» добавляет по уровню за ранг. По летающим не бьёт. Настройки в `SPELLS` и `HERO` в
`src/game/config.ts`, логика в `src/game/spells.ts` и `src/game/hero.ts`.

## Башни

| Башня | Роль | Особенность | Специализации 4-го уровня |
| --- | --- | --- | --- |
| Кислотные стрелки | быстрый одиночный урон | достают летающих | Снайперы (дальность, пробитие панциря) / Залп (два плевка по разным целям) |
| Казарма солдат | три муравья-солдата держат врага на тропе | не держат летающих | Броненосцы (здоровье и броня) / Жнецы (четверо с огромным уроном) |
| Грибница | облако спор: замедление + яд | яд игнорирует панцирь, бьёт по воздуху | Гниль (яд втрое сильнее) / Дурман (почти стоп и оглушение при входе) |
| Семенная катапульта | медленный урон по площади | только по земле | Камнемёт (валун с оглушением) / Семенной дождь (три семени веером) |

Три базовых уровня, затем развилка из двух специализаций. Продажа возвращает 60 %.

У стреляющих башен есть общий режим цели, кнопка с прицелом внизу слева от кнопки волны:
«первый» бьёт того, кто ближе всех к муравейнику, «последний» того, кто только вошёл в радиус,
«ближний» ближайшего к самой башне, «крепкий» врага с самым большим здоровьем, «слабый» добивает
самого слабого. Режим один на все башни, выбор запоминается между уровнями; казарме он не нужен,
солдаты держат того, кто подошёл. Список в `TARGET_MODES` в `src/game/config.ts`, выбор цели в
`Tower.pickMany` по `GameCtx.targetMode`.

## Постройка башен

Башня не появляется мгновенно. По тапу из муравейника выбегают трое рабочих в касках: один с
молотком, двое несут лестницу. У клетки появляются утоптанная земля и леса, лестницу прислоняют,
все трое стучат молотками, и башня поднимается из земли; потом рабочие бегут обратно и скрываются
в муравейнике. Стройка длится время пути (скорость рабочих 460 px/с) плюс 1,8 с работы, улучшение
и специализация — плюс 1,4 с; всё это время башня не стреляет, а солдаты новой казармы выходят
только после первой стройки. Продажа во время стройки отправляет рабочих домой. Хореография в
`src/game/construction.ts`, готовность башни считает `Tower` (`building`, `progress`), каска,
молоток, лестница и леса нарисованы в `art.ts`. Робот в симуляции строит с той же задержкой.

| Жук-носорог | босс, панцирь 50 %, стоит 5 личинок |
| Термитная матка | мини-босс: много здоровья, регенерирует, каждые 8 с выпускает двух термитов позади себя, стоит 10 личинок |
| Стрекоза | летает быстро и крепко: проверка противовоздушной обороны |
| Пиявка | медленная, живучая, регенерирует, стоит 2 личинки |
| Термит-подрывник | при смерти взрывается и ранит солдат и героя рядом: казармы дорого обходятся |
| Королева термитов | финальный босс: панцирь 40 %, регенерация, призывает термитов-солдат, стоит 20 личинок |

Боссов (носорог, матка, королева) нельзя держать вечно: после 5–6 с удержания подряд босс
делает «Напор» — бьёт и оглушает солдат и героя вокруг, сбрасывает того, кто его держал, и
несколько секунд идёт сквозь строй быстрее обычного. Над полоской здоровья видна дуга
удержания; когда она замыкается, пора отводить дружину. Поле `boss` в `ENEMIES`.

Здоровье врагов растёт на 4 % за волну. Враг с полем `spawn` в `ENEMIES` призывает других,
с полем `explode` взрывается при смерти; так собираются новые боссы без кода.

## Баланс: симуляция без браузера

```bash
npm run sim                 # все уровни, 3 партии на стратегию, «Нормально»
npm run sim 3 5             # только третий уровень, 5 партий
npm run sim all 3 hard      # все уровни на «Сложно» (easy | normal | hard)
npm run sim tutorial        # обучение
npm run sim endless 3       # бесконечная осада: до какой волны дожил робот
npx tsx sim/tutorial.ts     # обучение строго по подсказкам
```

Игрок-робот (`sim/policy.ts`) ставит башни на клетки с лучшим покрытием троп (сколько
пикселей тропы попадает в радиус), качает самые полезные, выбирает специализации, бьёт
заклинаниями по скоплению у финального участка тропы и зовёт волны раньше, когда поле чистое.
`npx tsx sim/debug.ts 4` печатает сетку уровня и постройки робота по волнам. Пять стратегий:
смешанная ранняя и терпеливая, «качать, а не строить», только стрелки, без заклинаний. Отчёт
показывает победы, уцелевших личинок, утечки по волнам, число заклинаний и долю урона каждого
источника. Робот играет хуже человека, поэтому цель баланса: на «Нормально» смешанная ранняя
стратегия проходит каждый уровень с запасом (сейчас 6–20 личинок из 20, самые тугие —
четвёртый и пятый), на «Легко» почти без потерь, а на «Сложно» (враги на 15 % крепче, личинок вдвое меньше)
робот берёт первый акт лишь некоторыми стратегиями и проигрывает второй — этот режим для
человека, который умеет целиться заклинаниями.

В бесконечной осаде робот играет так же, только башен ставит чуть больше. Он играет хуже
человека, поэтому это нижняя граница: сейчас на «Нормально» он отбивает 18–32 волны (в среднем около
25, забег 15–20 минут), на «Легко» 33–45, на «Сложно» 9–13.

## Как добавить уровень

Карты кампании проще всего добавлять генератором: опиши карту в `specs()` в `sim/campaign.ts`
(тема, число троп, полоса, стена, пень, препятствия, волны, нектар), сгенерируй, подбери сложность
и допиши название в `src/game/maptexts.ts`. Уровень вручную: в `src/game/levels.ts` опиши новый
`LevelDef`: тропы как списки точек (каждая заканчивается у
входа в муравейник; соседние точки должны отличаться только по x или только по y, то есть
тропа состоит из горизонтальных и вертикальных отрезков с поворотами на 90°, а внутренние
точки лежат на центрах клеток `40 + 80·k`), волны с указанием тропы для каждой группы, тему
карты и текст истории. Площадки задавать не нужно: сетка застройки строится сама. Добавь уровень
в `HANDMADE` и поставь на место в акте в `HAND_SLOTS` в `src/game/campaign.ts`. Тема карты
(`LevelTheme`) задаёт палитру, доли декора и декорации: ствол павшего дуба (`oak`), ночь со
светлячками (`night`), гнилой пень с норой (`stump`), ручей с мостами там, где его пересекают
тропы (`water`), стену термитника с норами в начале троп (`wall`) и пещеру (`cave`); у новых
актов ещё ландшафт (`biome`), вид полосы (`bandKind`: вода, лёд, ущелье, ручей с карпами) и
препятствия (`blobs`).
Правило дизайна, которое подтвердила симуляция: несколько троп должны сливаться задолго до
лагеря, иначе защищать приходится каждую по отдельности и уровень не проходится.

## Как заменить арт на нарисованный вручную

Все визуалы проходят через функции в `src/render/art.ts`: `drawAnt`, `drawBeetle`,
`drawTowerAcid` и так далее. Когда появятся спрайты, каждая функция меняется по одной: вместо
рисования фигурами — `ctx.drawImage` нужного кадра. Игровая логика об этом не знает.
Логическое разрешение 1280x720 и размеры сущностей (муравей ~36 px, башня ~80 px) — ориентир
для размеров спрайтов; на телефонах с высокой плотностью рисуй в 2x. Существа сейчас
поворачиваются на любой угол, поэтому для спрайтов понадобятся либо 8 направлений с кадрами
ходьбы, либо один вид сверху, который поворачивается кодом.

## Заставка главного меню

Титульный экран показывает художественную картину (`src/assets/sprites/splash.webp`, 1280×720,
вшивается в сборку как base64, около 160 КБ): закатный луг, муравейник с флажком и башнями слева,
Жвал с солдатами в центре, колонна термитника справа. Картина нарисована по промпту с описанием наших
героев вне проекта и положена в `src/assets/splash/` (там лежат исходники-кандидаты `splash_a.jpg` и
`splash_b.jpg`). Страница `splash.html` (только dev) вписывает выбранный исходник в 1280×720 с обрезкой
по краям и сохраняет WebP через dev-плагин: `http://localhost:5173/splash.html?src=/src/assets/splash/splash_b.jpg&q=0.88`.
Поверх картины игра рисует деревянную табличку с названием, кнопку и подсказку (`src/render/splash.ts`,
`UI.drawTitle`); пока картина не загрузилась, фоном служит векторная диорама из тех же рисунков, что
и спрайт-листы.

## Пекарня спрайтов и спрайты в игре

`npm run dev`, затем открой `http://localhost:5173/sprites.html`: страница растеризует векторные
рисунки существ из `src/sprites/` в листы «8 направлений × 6 кадров ходьбы» (кадр 128 px, то есть
2x к игре, фон прозрачный, тени нет: её рисует игра), показывает каждый лист и живой превью в игровом
масштабе и сохраняет `src/assets/sprites/<имя>.png` (эталон для просмотра), `<имя>.webp` (качество 0.9, его вшивает игра, он втрое меньше PNG) и `<имя>.json` (раскладка). Параметр
`?only=ant_hero` печёт один лист. Направления идут по часовой стрелке от востока (E, SE, S, SW, W,
NW, N, NE), угол равен индексу × 45°. Рисунок существа смотрит вдоль +x; поворот, наклон камеры
(сжатие по вертикали 0.86), свет сверху экрана и блик пекарня добавляет сама, поэтому один рисунок
даёт все восемь проекций с одинаковым освещением. Общая раскладка в `src/sprites/layout.ts`,
код пекарни в `src/sprites/bake.ts`, dev-плагин сохранения в `vite.config.ts`.

В игре листы подключает `src/render/sprites.ts`: он импортирует WebP (в сборке они вшиваются в
`index.html` как base64, около 0,1 МБ на лист; семнадцать листов дают сборку в 2,5 МБ) и отдаёт в `art.ts` рисовальщик через
`setSpriteDrawer`. Функции `drawAnt` и `drawHero` сначала пробуют спрайт: направление берётся
округлением угла до 45°, кадр — из фазы шага; пока картинка не загрузилась, существо рисуется
векторно. Симуляция в Node этот модуль не импортирует и всегда работает с векторами. Сейчас на
спрайтах всё семейство муравьёв: рабочий (в том числе строители и муравьи на кислотной башне),
солдат казармы и дружины, Жвал с доспехом и чёрный налётчик, а из врагов — три термита: обычный, солдат и подрывник (свечение подрывника игра рисует под спрайтом), паук, жук-щитоносец, жук-носорог, оса и шершень (у летающих кадры листа — взмахи крыльев, фаза идёт от времени), слизень и пиявка (кадры — волна по телу), стрекоза, термитная матка и королева (эти два листа нарисованы плотнее и берутся в игре с собственным множителем размера). Векторными остались башни, муравейник и декор карты.
